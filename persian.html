پروژه‌ها :


Get Price : سیستمی که با استفاده از APIهای بازارهای مالی کار می‌کند و شامل یک اپلیکیشن دسکتاپ گرافیکی، ربات تلگرام و رابط ترمینال است.


Persian Text to Speech : یک اپلیکیشن دسکتاپ ساخته‌شده با Python که متن را با استفاده از Google API به گفتار تبدیل می‌کند.


QR Code Creator : یک اپلیکیشن دسکتاپ برای تبدیل متن یا فایل متنی به QR Code که با کتابخانه qrcode در Python ساخته شده است.


Simple Calculator : یک ماشین‌حساب گرافیکی ساخته‌شده با Python.


YouTube Downloader : یک اپلیکیشن دسکتاپ برای دانلود ویدیوهای YouTube از طریق لینک و انتخاب کیفیت موردنظر، ساخته‌شده با Tkinter و yt-dlp.


Voice Call to Text and Summary : یک اپلیکیشن گرافیکی Python که با استفاده از هوش مصنوعی تماس صوتی را به متن و خلاصه مکالمه تبدیل می‌کند و با OpenAI API ساخته شده است.


Google Translator Bot : یک ربات ترجمه که با استفاده از Google Translate API و Telegram Bot ساخته شده است.


Student Management System : یک پروژه دانشگاهی مبتنی بر ساختمان داده برای مدیریت دانشجویان، دروس دانشگاهی، نمرات و گزارش‌های کارکنان که با زبان C نوشته شده است.


Login Page : یک صفحه ورود ساده ساخته‌شده با HTML و CSS با تم مدرن و تیره.
